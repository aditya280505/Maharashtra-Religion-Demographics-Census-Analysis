## 📌 About the Project

The **Maharashtra Census Analytics Dashboard** analyzes Census data from 2001 and 2011 to understand how the state's population and demographic composition changed over a decade.

Built using **Microsoft Power BI**, the project transforms census datasets into visual insights through KPI cards, comparative charts, and demographic analysis.

### 🎯 Project Objectives

* 📈 Analyze population growth between 2001 and 2011.
* 🏙️ Compare rural and urban population trends.
* 👥 Explore religion-wise population distribution.
* 🔍 Examine changes in religion-wise population share.
* 📊 Present demographic insights through interactive visualizations.

## 📈 Key Findings

| 📌 Metric                     |   📊 Result |
| :---------------------------- | ----------: |
| Maharashtra Population — 2001 |  96,878,627 |
| Maharashtra Population — 2011 | 112,374,333 |
| Total Population Increase     |  15,495,706 |
| Population Growth — 2001–2011 |      15.99% |
| Rural Population — 2011       |  61,556,074 |
| Urban Population — 2011       |  50,818,259 |
| Increase in Urban Population  |   9,717,279 |

> **Key Insight:** Maharashtra's population increased by approximately **15.50 million** between 2001 and 2011. The urban population increased by approximately **9.72 million** during the same period.

*Source: Maharashtra Census data for 2001 and 2011.*

## 🚀 How to Explore the Dashboard
