# Data Dictionary

## 1. Maharashtra Population Comparison

| Column            | Description                                         |
| ----------------- | --------------------------------------------------- |
| Area_Type         | Population category, such as Total, Rural, or Urban |
| Population_2001   | Population recorded in 2001                         |
| Population_2011   | Population recorded in 2011                         |
| Population_Change | Difference between 2011 and 2001 population         |
| Growth_Percent    | Population growth percentage                        |
